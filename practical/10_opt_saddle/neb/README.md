## Описание задачи

В файле `in.sivac` описана процедура вычисления барьера диффузии вакансии в кристалле кремния методом Nudged Elastic Band.

## Задание

1. Запустить входной файл `in.sivac`:
```
mpirun -np N lammps -partition Nx1 -in in.sivac
```
2. Загрузить в OVITO файл `dump.neb.sivac.final.all.1`. Выбрать модификатор Slice, установив положение плоскости 8.062 и толщину слоя 3.
3. Найти положение вакансии.
4. Просмотреть все файлы с репликами NEB, увидеть, какие промежуточные состояния найдены этим методом.
5. Обработайте вывод LAMMPS приложенной программой на Python:
```
python3 process_neb_log.py log.lammps
```
6. Постройте с помощью gnuplot или другой программы профили энергии из файлов `neb_path.*`. Определите величину барьера миграции вакансии.
7. Предложите причины, почему на начальном шаге последняя конфигурация имеет столь высокую энергию.
