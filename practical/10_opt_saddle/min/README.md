## Описание задачи

В файле `in.opt.sivac` описана процедура минимизации энергии вакансии в кристалле кремния.

## Задание

1. Запустить входной файл `in.opt.sivac`:
```
lammps -in in.opt.sivac
```
2. Из файла `log.opt.cg` построить зависимость величины градиента энергии (в файл выводятся 
величины максимальной силы на атом и евклидова норма силы на $N$ атомов) от номера шага оптимизации.
3. Из наклона $\ln{f_{max}}(n_{iter})$ определить скорость сходимости метода сопряженных градиентов для оптимизации.
4. Повторить расчет, изменив способ оптимизации через ключ командной строки:
```
lammps -in in.opt.sivac -var minstyle quickmin
```
5. Сделать расчеты со всеми доступными стилями оптимизации - `sd`, `quickmin`, `fire`, `hftn`.
6. Определить скорость сходимости указанных методов. Наблюдается ли сверхлинейная сходимость квазиньютоновского метода `hftn`?
7. Сравнить минимальные значения энергии и силы, достигнутые каждым из методов. Критерием остановки алгоритма выбрано относительное изменение энергии между итерациями меньше $10^{-10}$ или максимальная величина силы меньше $10^{-8}$. Насколько близки параметры, на которых остановились разные методы, к этим значениям?
