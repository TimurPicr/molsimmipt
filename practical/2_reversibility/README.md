# Описание
В этой работе изучается обратимость конечно-разностной аппроксимации уравнений движения и ляпуновская расходимость динамических траекторий.

Рассматривается система со сглаженным потенциалом Леннард-Джонса
```math
U_{LJ}(r) = \begin{cases} 4\varepsilon \left[\left(\frac{\sigma}{r}\right)^{12} - \left(\frac{\sigma}{r}\right)^6\right], r \leq r_{in}, \\
ar^3 + br^2 + cr + d, r_{in} < r \leq r_{out} \\
0, r > r_{out}\end{cases}
```

Коэффициенты сглаживающего многочлена подбираются так, чтобы потенциал и его производная непрерывно сшивались с нулём на интервале от $`r_{in}`$ до $`r_{out}`$.

Численное нтегрирование уравнений движения проводится схемой Верле
```math
\begin{array}{l}
\vec{r}_i(t + \Delta t) = \vec{r}_i(t) + \vec{v}_i(t) + \frac{\vec{F}_i(t)}{m_i} \frac{\Delta t^2}{2}, \\
\vec{v}_i(t + \Delta t) = \vec{v}_i(t) + \frac{\vec{F}_i(t) + \vec{F}_i(t)}{m_i} \Delta t,
\end{array}
```
где $`\vec{F}_i(t)`$ - сила, действующая на $`i`$-ю частицу в момент времени $`t`$.

Из формул для вычисления координат и скоростей на временном слое $`t + \Delta t`$ легко видеть, что
```math
\vec{r}_i(t) = \vec{r}_i(t + \Delta t) - \vec{v}_i(t + \Delta t) + \frac{\vec{F}_i(t + \Delta t)}{m_i} \frac{\Delta t^2}{2},
```
т.е. численная схема обратима по времени - при замене $`\Delta t`$ на $`-\Delta t`$ (что эквивалентно обращению 
скоростей всех частиц в некоторый момент времени) численная траектория будет проходить по тем же самым точкам, 
но в обратном направлении.

Поскольку численная траектория не совпадает точно с истинной динамической траекторией, то, сравнивая две 
численные траектории, рассчитанные с разной длиной шага, можно охарактеризовать устойчивость системы 
уравнений движения: если две численные траектории будут близки, то решения уравнений устойчивы относительно 
малого возмущения начальных условий, в противном случае численные траектории со временем будут расходиться.

За счет обратимости численной схемы можно провести следующую схему: из начального состояния система интегрируется 
вперед на время $`T`$ с шагом $`\Delta t_1`$, затем скорости обращаются и система интегрируется назад на то же 
время, но с шагом $`\Delta t_2`$.

За характеристику "близости" траекторий через время $`T`$ можно взять сумму квадратов разностей положений 
частиц до и после интегрирования туда-сюда или сумму квадратов разностей скоростей в начальном и конечном состоянии.

По зависимости "расстояния" между траекториями от времени определяется параметр 
устойчивости системы.

Директория содержит входные файлы, необходимые для расчетов.

## Процедура расчета

Начальное состояние задано как двумерная кристаллическая решетка с атомами двух типов. 
Атомы разных типов выстроены так, чтобы при визуализации получался логотип LAMMPS.

Задаются случайные скорости с такой средней величиной, чтобы решётка расплавилась. 
Расчет ведется заданное количество временных шагов. Затем скорости всех атомов меняют 
направление, а длина временного шага уменьшается в заданное количество раз, после чего 
проводится следующая часть расчета. Число шагов интегрирования во второй части во 
столько же раз больше, чем в первой части, во сколько раз шаг интегрирования короче. 
В случае идеально обратимой траектории в конце должно было бы получиться абсолютно 
то же состояние, с которого начался расчет.

## Файлы
Входные файлы:
* `in.time-reverse` - основной входной файл. Содержит процедуру инициализации и описание процедуры расчета.
* `lammps_logo.inc` - файл, в котором описывается начальная структура.

Выходные файлы:
* `dump` - директория для записанных траекторий
    * `fwd.*.dump` - файлы с траекториями, рассчитанными в прямом направлениии
    * `back.*.dump` - файлы с траекториями, рассчитанными в обратном направлениии
* `log` - директория для логов расчетов
* `diff` - директория для файлов, в которые записаны "расстояния" между начальным и конечным состояниями

## Запуск
Расчет запускается командой `lmp_* -in in.time-reverse`.

При запуске входного файла LAMMPS может принять дополнительно значения переменных:
* `ts_fwd` означает длину шага в "прямом" расчете (в безразмерных леннард-джонсовских единицах, по умолчанию 0.005)
* `scale` - во сколько раз короче временной шаг в обратном расчете, чем в прямом (должно быть целым числом, по умолчанию 2)
* `nsteps` - сколько шагов по времени идет прямой расчет (целое число, по умолчанию 100)

Значения дополнительных переменных задаются ключом `-v <имя переменной> <значение>`. Т.е. 
```
lmp_xxx -in in.time-reverse -v ts_fwd 0.01 -v scale 10 -v nsteps 500
```
означает, что в прямом направлении будет сделано 500 шагов длиной 0.01, а в обратном - 5000 шагов длиной 0.001.

После расчета в директориях `dump`, `log` `diff` создаются новые файлы.

Файлы с траекториями в директории `dump` можно визуализировать во внешних утилитах, 
например, в OVITO (https://ovito.org). 
В файлах из директории `diff` содержится информация о том, насколько "далеко" конечное 
состояние от начального: предпоследнее число последней строки - квадрат отклонения по 
координатам, последнее число - квадрат отклонения по скоростям.
