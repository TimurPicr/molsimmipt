# Описание
В этой работе исследуется метод термодинамического интегрирования для получения избыточной свободной энергии жидкости.

В качестве примера рассматривается система частиц, взаимодействующих со сглаженным потенциалом Леннард-Джонса
```math
U_{LJ}(r) = \begin{cases} 4\varepsilon \left[\left(\frac{\sigma}{r}\right)^{12} - \left(\frac{\sigma}{r}\right)^6\right], r \leq r_{in}, \\
ar^3 + br^2 + cr + d, r_{in} < r \leq r_{out} \\
0, r > r_{out}\end{cases}
```
Коэффициенты сглаживающего многочлена подбираются так, чтобы потенциал и его производная непрерывно сшивались с нулём на интервале от $`r_{in}`$ до $`r_{out}`$.

Для жидкости или газа избыточную энергию Гельмгольца можно получить разными способами. 
В этой работе рассматриваются
* термодинамическое интегрирование c "удалением" одной из частиц
* возмущение свободной энергии

## Термодинамическое интегрирование
Термодинамическое интегрирование ведётся через изменение параметра $`\varepsilon`$ в потенциале Леннард-Джонса для одной из частиц системы. 
Если для этой частицы $`\varepsilon = \lambda\varepsilon_0`$, то общая потенциальная энергия зависит от параметра по закону $`U = \sum_{i<j\le N-1} U_{LJ}(r_{ij}) + \lambda \sum_{i\le N-1} U_{LJ}(r_{iN})`$, где $`U_{LJ}`$ - потенциал Леннард-Джонса c параметром $`\varepsilon = \varepsilon_0`$. Процесс соответствует постепенному "добавлению" в систему ещё одной частицы. Разница свободных энергий равна
```math
F_{N} - F_{N-1} = \int\limits_{0}^{1} \left\langle \frac{\partial U}{\partial \lambda}\right\rangle d\lambda,
```
Как можно видеть, $`\frac{\partial U}{\partial \lambda} = \langle \frac{U^N_{LJ}}{\lambda} \rangle`$, где $`U^N = \lambda \sum_{i\le N-1} U_{LJ}(r_{iN})`$ - энергия взаимодействия удаляемой $`N`$-й частицы с остальной системой.

Величина $`F_{N} - F_{N-1}`$ при достаточно большом числе $`N`$ близка к $`\left(\cfrac{\partial F^{ex}}{\partial N} \right)_{V,T} = \mu^{ex}`$ (производная равна избыточному химическому потенциалу, поскольку изменяется только энергия взаимодействия частицы с окружением, кинетическая энергия из системы не изымается).

На практике интегрирование будет проводиться в диапазоне $`\lambda = \lambda_{min}`$ до 1 методом трапеций. При достаточно малом значении $`\lambda_{min}`$ и большом числе точек интегрирования интеграл должен сходиться к постоянному значению.

## Возмущение свободной энергии

Для вычисления изменения свободной энергии при замене потенциала с $`U_0`$ на $`U_1`$ можно воспользоваться формулой
```math
F_1 - F_0 = -kT \ln{\left\langle \exp{\left(-\frac{U_1 - U_0}{kT}\right)} \right\rangle_0},
```
где усреднение берётся по каноническому распределению для системы с потенциалом $`U_0`$, а $`U_1 - U_0`$ -- это гипотетическое изменение потенциальной энергии при замене потенциала при фиксированной конфигурации частиц.

Таким образом, по тому же набору траекторий, что использовались для термодинамического интегрирования, можно рассчитать изменение свободной энергии по другой формуле:
```math
F_{N} - F_{N-1} = F(\lambda=1) - F(\lambda=0) \approx F(\lambda=\lambda_M) - F(\lambda=\lambda_{min}) = (F(\lambda_M)-F(\lambda_{M-1})) + (F(\lambda_{M-1})-F(\lambda_{M-2})) + \dots + (F(\lambda_1)-F(\lambda_{min}))
```

Поскольку меняется только взаимодействие $`N`$-й частицы с остальными, то $`U(\lambda_{k+1})-U(\lambda_{k}) = U^N(\lambda_{k+1})-U^N(\lambda_{k}) = (\lambda_{k+1} - \lambda_{k})U^N(\lambda=1) = (\lambda_{k+1} - \lambda_{k})U^N(\lambda_k) / \lambda_k`$.

## Процедура расчета

Скрипт `in.ti_fluid_trap` создает систему, в которой $`N-1`$ частиц относятся к одному типу и одна частица - ко второму. При запуске файла проводится ряд расчетов с разными параметрами $`\varepsilon`$ потенциала Леннард-Джонса для взаимодействия между атомами первого и второго типа, где $`\varepsilon_i = \lambda_i, \lambda_0 = \lambda_{min}, \lambda_i = i / M, i = 1, \dots, M`$, где $`M`$ -- число отрезков, по которым проводится численное интегрирование. Результаты расчетов выводятся в файл с названием `ti_fluid.*.log`. Отдельно выводится энергия взаимодействия "мутируемого" атома с остальной системой в файлы `ti_energy.*.log`.

## Файлы
Входные файлы:
* `in.ti_fluid_trap` - входной файл с реализацией термодинамического интегрирования

Выходные файлы:
* `ti_fluid.*.log` - информация о расчетах с изменяющимся параметром потенциала
* `ti_energy.*.log` - энергия взаимодействия "мутируемого" атома с остальной системой

## Запуск
`lmp_* -in in.ti_fluid_trap` - для термодинамического интегрирования

Дополнительные параметры:
* `-var d ⟨значение⟩` - изменение плотности, для которой будет проводиться расчет (по умолчанию равна 0.84)
* `-var temperature ⟨значение⟩` - изменение температуры, поддерживаемой термостатами (по умолчанию равна 1.0)
* `-var lambda_min ⟨значение⟩` - изменение минимального значения $`\lambda`$ (по умолчанию 0.001)
* `-var n_steps ⟨значение⟩` - число отрезков для численного интегрирования (по умолчанию 25)
* `-var prod_length ⟨значение⟩` - число шагов МД моделирования в каждой траектории для набора статистики (по умолчанию 100000)
