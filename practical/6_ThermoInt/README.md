# Описание
В этой работе исследуется метод термодинамического интегрирования для получения избыточной свободной энергии жидкости.

В качестве примера рассматривается система частиц, взаимодействующих со сглаженным потенциалом Леннард-Джонса
```math
U_{LJ}(r) = \begin{cases} 4\varepsilon \left[\left(\frac{\sigma}{r}\right)^{12} - \left(\frac{\sigma}{r}\right)^6\right], r \leq r_{in}, \\
ar^3 + br^2 + cr + d, r_{in} < r \leq r_{out} \\
0, r > r_{out}\end{cases}
```
Коэффициенты сглаживающего многочлена подбираются так, чтобы потенциал и его производная непрерывно сшивались с нулём на интервале от $`r_{in}`$ до $`r_{out}`$.

Для жидкости или газа избыточную энергию Гельмгольца можно получить разными способами. 
В этой работе рассматриваются
* термодинамическое интегрирование c "удалением" одной из частиц
* зонтичная выборка

Термодинамическое интегрирование ведётся через изменение параметра $`\varepsilon`$ в потенциале Леннард-Джонса для одной из частиц системы. 
Если для этой частицы $`\varepsilon = \lambda\varepsilon_0`$, то общая потенциальная энергия зависит от параметра по закону $`U = \sum_{i<j\le N-1} U_{LJ}(r_{ij}) + \lambda \sum_{i\le N-1} U_{LJ}(r_{iN})`$, где $`U_{LJ}`$ - потенциал Леннард-Джонса c параметром $`\varepsilon = \varepsilon_0`$. Процесс соответствует постепенному "добавлению" в систему ещё одной частицы. Разница свободных энергий равна
```math
F_{N} - F_{N-1} = \int\limits_{0}^{1} \left\langle \frac{\partial U}{\partial \lambda}\right\rangle d\lambda,
```
Как можно видеть, $`\frac{\partial U}{\partial \lambda} = \langle \frac{U^N_{LJ}}{\lambda} \rangle`$, где $`U^N = \lambda \sum_{i\le N-1} U_{LJ}(r_{iN})`$ - энергия взаимодействия удаляемой $`N`$-й частицы с остальной системой.

Величина $`F_{N} - F_{N-1}`$ при достаточно большом числе $`N`$ близка к $`\left(\frac{\partial F^{ex}}{\partial N} \right)_{V,T} = \mu^{ex}`$ (производная равна избыточному химическому потенциалу, поскольку изменяется только энергия взаимодействия частицы с окружением, кинетическая энергия из системы не изымается).

На практике интегрирование будет проводиться в диапазоне $`\lambda = \lambda_{min}`$ до 1 методом трапеций. При достаточно малом значении $`\lambda_{min}`$ и большом числе точек интегрирования интеграл должен сходиться к постоянному значению.

## Процедура расчета

В файле `in.ti_integ` занесены координаты узлов квадратурной формулы Гаусса-Кронрода по 15 точкам (7 точек для квадратуры Гаусса, 8 дополнительных точек для уточняющей формулы Кронрода). Скрипт создает систему, в которой $`N-1`$ частиц относятся к одному типу и одна частица - ко второму. При запуске файла проводится 15 расчетов с разными параметрами $`\varepsilon`$ потенциала Леннард-Джонса для взаимодействия между атомами первого и второго типа, где $`\varepsilon_i = f(\lambda_i), \lambda_i = \lambda_{min} + x_i (\lambda_{max} - \lambda_{min})`$, $`f(\lambda) = e^\lambda + c`$, $`c = 10^{-5}`$, минимальное и максимальное значение $`\lambda`$ написаны выше, $`x_i`$ - узлы квадратурной формулы на отрезке $`[0; 1]`$. Результаты расчетов выводятся в файл с названием `ti_fluid.*.log`. Отдельно выводится энергия взаимодействия "мутируемого" атома с остальной системой в файлы `ti_energy.*.log`.

## Файлы
Входные файлы:
* `in.ti_fluid_trap` - входной файл с реализацией термодинамического интегрирования
* `in.umbrella_fluid` - входной файл с реализацией метода возмущения свободной энергии

Выходные файлы:
* `ti_fluid.*.log` - информация о расчетах с изменяющимся параметром потенциала
* `ti_energy.*.log` - энергия взаимодействия "мутируемого" атома с остальной системой
* `fep_fluid.*.log` - информация о расчетах с изменяющимся параметром потенциала для метода возмущения свободной энергии
* `fep_energy.*.log` - энергия взаимодействия "мутируемого" атома с остальной системой

## Запуск
`lmp_* -in in.ti_fluid_trap` - для термодинамического интегрирования
`lmp_* -in in.umbrella_fluid` - для вычислений методом Уидома

Дополнительные параметры:
* `-var d ⟨значение⟩` - изменение плотности, для которой будет проводиться расчет (по умолчанию равна 0.84)
* `-var temperature ⟨значение⟩` - изменение температуры, поддерживаемой термостатами (по умолчанию равна 1.0)

## Задание
1. Запустить входные файлы `in.ti_fluid` и `lmp_* -in in.widom`, задав в параметрах одинаковые значения плотности и температуры.
2. С помощью программы постобработки получить 15 значений средней потенциальной энергии из файлов `ti_energy.*.txt`.
3. Найти значения интеграла $`\int_{\lambda_{min}}^{\lambda_{max}} \frac{df}{f(\lambda) d\lambda} U`$ по формулам Гаусса и Кронрода (файлы пронумерованы по убыванию величины $`f(\lambda)`$). Определить из этих значений избыточную энергию Гельмгольца и оценить её погрешность.
4. Из файла `fluid_widom_main.log` получить среднюю величину избыточного химического потенциала (из последнего столбца термодинамического вывода) и давления с полным потенциалом при выбранных условиях.
5. Из избыточного химического потенциала и полного давления рассчитать избыточную энергию Гельмгольца и сопоставить с той, что получена методом термодинамического интегрирования.
