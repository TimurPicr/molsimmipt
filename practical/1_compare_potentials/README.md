# Описание
В этой работе сравниваются результаты, получаемые с парным и многочастичным потенциалом.

В качестве примера рассмотрена холодная кривая (т.е. зависимость энергии или давления от удельного объема при T=0) кристаллической меди.

Директория содержит входные файлы, необходимые для расчетов.

## Процедура расчета
Для расчета задается начальное состояние в виде гранецентрированной кубической решетки с ребром куба 3,2 $`\AA`$. Это меньше, чем равновесное значение для меди, и в ходе расчета оно будет увеличиваться.

Всего задается система 10×10×10 элементарных кубов.

Начальные скорости не задаются, т.е. атомы остаются неподвижными.

В ходе расчета размер расчетной области меняется до куба с ребром 50 $`\AA`$. Положения атомов меняются пропорционально.

Каждый шаг выводятся значения:
* номер шага
* полный объем расчетной области (в $`\AA^3`$)
* объем, приходящийся на один атом (в $`\AA^3`$)
* плотность (в $`г/см^3`$)
* полная потенциальная энергия системы (в эВ)
* потенциальная энергия на атом (в эВ)
* давление (в бар)

Расчет может проводиться либо с многочастичным потенциалом погруженного атома (EAM), либо с потенциалом Морзе.

Потенциал EAM имеет фиксированный радиус обрезания 4,95 $`\AA`$, заданный в файле с его описанием. Радиус обрезания потенциала Морзе можно задать в качестве входного параметра.
## Файлы
* `lammps.input` - основной входной файл. Содержит задание начальной конфигурации и описание процедуры расчета холодной кривой.
* `potentials` - директория, в которой хранятся файлы с параметрами потенциала.
    * `MORSE.potential` - файл с описанием и параметрами потенциала Морзе для меди
    * `EAM.potential` - файл с описанием потенциала погруженного атома
    * `Cu_u3.eam` - файл с табулированными функциями, необходимыми для расчета потенциала погруженного атома
## Запуск
Расчет запускается командой `lmp_* -in lammps.input`.

При запуске входного файла LAMMPS может принять дополнительно два значения переменных:

`ptype` означает тип потенциала (допустимые значения - `eam` и `morse`, по умолчанию EAM)

`morse_rcut` означает радиус обрезания потенциала Морзе в ангстремах (по умолчанию такой же, как и у потенциала EAM - 4,95 $`\AA`$).

Значения дополнительных переменных задаются ключом `-v <имя переменной> <значение>`. Т.е. для потенциала Морзе с радиусом обрезания 5,5 $`\AA`$ нужна следующая команда:

`lmp_xxx -in lammps_input -v ptype morse -v morse_rcut 5.5`

После расчета в рабочей директории создается файл `log.<тип потенциала>.<радиус обрезания>`, например, `log.eam.4.95` или `log.morse.5.5`. Основная необходимая информация - это "термодинамический вывод", который идет после строки

`Step Volume v_atomic_volume Density PotEng v_energy_peratom Press`.

Для обработки результатов используются скрипты `plot-pressure.sh` и `plot-energy.sh`, которые автоматически строят графики зависимостей давления и энергии от атомного объема при помощи [gnuplot](http://www.gnuplot.info/). Пример использования:
`./plot-pressure.sh log.morse.5.0 log.morse.5.8 log.eam.4.95`
## Задание
1. Запустить входной файл `lammps.input` без дополнительных ключей, тогда пройдет расчет с параметрами по умолчанию - потенциал EAM.
1. Запустить входной файл `lammps.input` с ключами `-v ptype morse -v morse_rcut 5.0`. Посмотреть, какие файлы при этом создаются.
1. Получить выходные файлы с потенциалом Морзе еще для 3-4 радиусов обрезания от 5 до 7 $`\AA`$.
1. Построить графики зависимостей давления от атомного объема с помощью прилагаемого скрипта. Сравнить различные радиусы обрезания потенциала Морзе с EAM потенциалом.
1. Для всех радиусов обрезания найти равновесный атомный объем с точностью до 3-4 значащих цифр. Пересчитать в плотность, используя атомную массу меди (значение найти в файле `lammps.input`). Сравнить с величиной из Википедии.
1. Построить графики в координатах энергия-объем при помощи `plot-energy.sh`.
