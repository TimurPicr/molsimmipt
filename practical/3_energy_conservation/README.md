# Описание
В этой работе изучается сохранение энергии с интегратором Верле и иерархическим интегратором rRESPA.

Рассматриваются две системы.

Первая - система со сглаженным потенциалом Леннард-Джонса
```math
U_{LJ}(r) = \begin{cases} 4\varepsilon \left[\left(\frac{\sigma}{r}\right)^{12} - \left(\frac{\sigma}{r}\right)^6\right], r \leq r_{in}, \\
ar^3 + br^2 + cr + d, r_{in} < r \leq r_{out} \\
0, r > r_{out}\end{cases}
```
Коэффициенты сглаживающего многочлена подбираются так, чтобы потенциал и его производная непрерывно сшивались с нулём на интервале от $`r_{in}`$ до $`r_{out}`$.

Вторая - система димеров, т.е. двухатомных молекул, с гармонической связью между частицами димера 
и сглаженным потенциалом Леннард-Джонса между димерами.

Cхема Верле выглядит следующим образом:
```math
\begin{array}{l}
\vec{r}_i(t + \Delta t) = \vec{r}_i(t) + \vec{v}_i(t) + \frac{\vec{F}_i(t)}{m_i} \frac{\Delta t^2}{2}, \\
\vec{v}_i(t + \Delta t) = \vec{v}_i(t) + \frac{\vec{F}_i(t) + \vec{F}_i(t)}{m_i} \Delta t,
\end{array}
```
где $`\vec{F}_i(t)`$ - сила, действующая на $`i`$-ю частицу в момент времени $`t`$.

В случае, когда система имеет степени свободы с сильно отличающимися характерными временами, 
шаг по времени нужно брать гораздо меньше, чем период самых быстрых колебаний. Вычислительно 
это может быть затратно: например, если система состоит из димеров с очень жесткими связями, 
то "быстрые" движения связаны с взаимодействием каждого атома только с одним другим атомом; 
интегрирование же всей системы с коротким шагом приводит к тому, что на каждом шагу 
рассчитывается взаимодействие каждого атома со всеми остальными внутри радиуса обрезания 
потенциала.

Одно из решений задачи - разделить степени свободы системы на "быстрые" и "медленные" и 
внутри одного шага интегрирования для "медленной" степени свободы делать несколько шагов для 
"быстрых" степеней свободы. Одним из методов, реализующих эту идеологию, является схема 
rRESPA.

Директория содержит входные файлы, необходимые для расчетов.

## Процедура расчета

Рассматривается две задачи.

Первая задача - посмотреть поведение полной энергии леннард-джонсовой системы от времени 
в зависимости от длины шага численного интегрирования.

Вторая задача - сравнить поведение полной энергии в системе димеров при интегрировании 
схемой Верле и схемой rRESPA с той же длиной "внешнего" шага интегрирования.

## Файлы
Входные файлы:
* `in.melt` - входной файл для системы леннард-джонсовских частиц.
* `in.molecule.verlet` - входной файл для системы димеров и интегрирования схемой Верле.
* `in.molecule.respa` - входной файл для системы димеров и интегрирования схемой rRESPA.
* `molecule.dimer` - описание топологии димера для двух предыдущих файлов.
