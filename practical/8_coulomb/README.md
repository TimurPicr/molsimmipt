# Описание
В работе анализируются различные методы расчета электростатических взаимодействий
в молекулярной динамике. Сопоставляются "точные" методы расчета, основанные на 
расчете дальнодействующих сил в обратном пространстве, и приближенные, основанные 
на обрезании потенциала в электронейтральной системе.

В качестве модели взят кристалл поваренной соли NaCl. Взаимодействие между атомами 
представлено в виде суммы потенциала Леннард-Джонса и электростатического взаимодействия.

В качестве эталонного расчета берется метод particle-particle-particle-mesh (PPPM).
С ним сопоставляются
*  метод суммирования по Эвальду
*  простое обрезание кулоновского потенциала на заданном расстоянии $`r_{cut}`$
```math
U_{ij,Coul}(r) = \begin{cases}{\frac{q_i q_j}{r}, r \leq r_{cut}}\\{0, r > r_{cut}}\end{cases}
```
*  Дебаевское экранирование
```math
U_{ij,Debye}(r) = \begin{cases}{\frac{q_i q_j}{r}e^{-\kappa r}, r \leq r_{cut}}\\{0, r > r_{cut}}\end{cases}
```
*  Экранирование со сдвигом по силам
```math
U_{ij,DSF}(r) = \begin{cases}{{q_i q_j}\left[\frac{\text{erfc}(\kappa r)}{r} - \frac{\text{erfc}(\kappa r_{cut})}{r_{cut}} +\left(\frac{\text{erfc}(\kappa r_{cut})}{r^2_{cut}}+\frac{2\kappa}{\sqrt\pi} \frac{\exp(-\kappa^2r^2_{cut})}{r_{cut}}\right) \left(r - r_{cut}\right) \right], r \leq r_{cut}}\\{0, r > r_{cut}}\end{cases}
```

## Процедура расчета
Разные методы дают разное абсолютное значение энергии, поэтому сравнение по абсолютным 
энергиям было бы некорректно. Вместо этого сравниваются разницы энергий между некоторой 
произвольной конфигурацией и идеальной кристаллической решеткой.

Опорная конфигурация получается путем проведения короткого МД расчета с потенциалом, 
вычисленным методом PPPM. Затем состояние сохраняется, его можно повторно загрузить,
поменять метод расчета электростатического взаимодействия и заново вычислить величину 
энергии электростатических взаимодействий.

## Входные файлы
*  `lattice.conf` - вспомогательный файл, в котором записаны параметры решетки NaCl,
константы Леннард-Джонсовского взаимодействия, массы и заряды частиц. Включается в остальные файлы при помощи команды `include`.
*  `in.nacl.pppm` - расчет по методу PPPM и генерация опорной конфигурации. Принимает 
значение переменной `kspc_tol` в качестве параметра, что определяет точность расчета 
дальнодействующих сил.
*  `in.nacl.ew` - расчет с суммированием по Эвальду. Требует заранее сохраненной
конфигурации, полученной при запуске предыдущего файла. Принимает значение переменной `kspc_tol` в качестве параметра, что определяет точность расчета дальнодействующих сил. 
Для сравнения с PPPM эти параметры для обоих методов должны быть равны.
*  `in.nacl.coul_cut` - расчет с простым обрезанием кулоновского взаимодействия. 
Принимает значение переменной `coul_rcut` в качестве параметра, что задает радиус 
обрезания кулоновского взаимодействия.
*  `in.nacl.debye` - расчет с дебаевским экранированием кулоновского взаимодействия. 
Принимает значение переменной `kappa` в качестве параметра, что задает константу 
экранирования.
*  `in.nacl.dsf` - расчет с экранированием кулоновского взаимодействия и смещением 
по силам. Принимает значение переменной `kappa` в качестве параметра, что задает константу экранирования.
