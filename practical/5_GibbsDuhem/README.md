# Интегрирование кривой фазового равновесия (уравнения Клапейрона-Клаузиуса / Гиббса-Дюгема)

Кривая фазового равновесия для фазового перехода I рода в однокомпонентной системе 
описывается дифференциальным уравнением Клапейрона-Клаузиуса
```math
\frac{dP}{dT} = \frac{\Delta s}{\Delta v} = \frac{\Delta h}{T \Delta v},
```
где $`\Delta s`$ и $`\Delta v`$ - разности мольных энтропий и объемов фаз на линии равновесия при давлении
$`P`$ и температуре $`T`$, $`\Delta h`$ - разность мольных энтальпий фаз на линии равновесия.

Уравнение Клапейрона-Клаузиуса при известной начальной точке $`(P_0, T_0)`$ можно рассматривать 
как задачу Коши, которая может быть решена численно для получения кривой равновесия.

Как видно из уравнения Клапейрона-Клаузиуса, для получения величин в правой части уравнения 
требуются только свойства фаз по отдельности, что позволяет избежать моделирования двухфазных систем.

В работе предлагается найти давление $`P_1`$ насыщенного пара при температуре $`T_1`$, если известны давление 
и температура $`P_0`$ и $`T_0`$ в некоторой начальной точке на кривой испарения.

Интегрирование может производиться любым методом численного интегрирования. Например, два метода из семейства 
методов Рунге-Кутты 2-го порядка:

Метод Эйлера с пересчётом (метод Хойна):
```math
\begin{array}{l}
{\tilde P} = P(T) + \Delta T \cdot f(P, T) (\text{предиктор давления при } T + \Delta T)\\
P(T + \Delta T) = P(T) + \frac{\Delta T}{2} \left( f(P, T) + f({\tilde P}, T + \Delta T)\right) (\text{шаг-корректор для давления})
\end{array}
```
Метод центральной точки:
```math
\begin{array}{l}
{\tilde P} = P(T) + \frac{\Delta T}{2} f(P, T) (\text{приближенное давление при } T + \frac{\Delta T}{2})\\
P(T + \Delta T) = P(T) + \Delta T \cdot f(\tilde P, T + \frac{\Delta T}{2})
\end{array}
```

В этих формулах $`f(P,T) = \frac{\Delta h(P,T)}{T \Delta v(P,T)}`$, где разницы энтальпий и удельных объёмов фаз 
вычисляются из атомистического моделирования.

## Процедура расчета

Путем моделирования в ансамбле Гиббса для системы Леннард-Джонса получены плотности пара и жидкости 
при температуре $`T_0^* = 0.9`$, равные $`\rho_{gas}^* = 0.01532`$ и $`\rho_{liq}^* = 0.7518`$. Вначале 
запуском скрипта `in.nvt` проводятся равновесные *NVT* расчёты с этими начальными плотностями, которые 
генерируют начальные конфигурации для последующих запусков. Из термодинамического вывода для газовой 
фазы необходимо определить начальное давление $`P_0^*`$.

После генерации начальных файлов `gas.T0.9.restart` и `liq.T0.9.restart` все последующие расчеты ведутся 
в *NPT* ансамбле. Выбирается шаг численного интегрирования $`\Delta T`$ и схема численного интегрирования. 
Затем запускается нужное количество раз `in.npt` для проведения расчетов при постоянном давлении, чтобы 
вычислить необходимые промежуточные значения $`\tilde P`$. Из расчетов берутся средние энтальпии и объемы 
фаз.

## Файлы

* `in.nvt` - файл для подготовки начальных конфигураций
* `in.npt` - файл для проведения основных расчетов

## Запуск

*NVT* расчет запускается командой `lmp_* -in in.nvt`.

При запуске нужно указать, для какой плотности и температуры будет проводиться расчёт:
* `d` задает плотность (в безразмерных леннард-джонсовских единицах, по умолчанию 0.01532)
* `init_T` - температура (по умолчанию 0.9)

Значения дополнительных переменных задаются ключом `-v <имя переменной> <значение>`. Т.е.
```
lmp_xxx -in in.nvt -v d 0.01532 -v init_T 0.9
```
означает, расчёт для плотности 0.01532 и температуры 0.9.

Для начальных конфигураций нужно произвести два запуска с одинаковой температурой и двумя 
плотностями, соответствующими плотностям пара и жидкости при выбранной температуре (предполагается, 
что характеристики в начальной точке получены из расчётов в ансамбле Гиббса, методом прямого 
сосуществования или каким-либо другим способом).

Затем проводится серия *NPT* расчётов, чтобы получить необходимые для численного интегрирования 
характеристики. Эти расчёты запускаются через `lmp_* -in in.npt`

При запуске нужно указать, для какой фазы, давления и температуры будет проводиться расчёт и 
рестарт-файл для какой температуры использовать для чтения начального состояния:
* `phase` - для какой фазы будет расчёт (может иметь значения `gas` или `liq`)
* `pe` - давление
* `T_prod` - температура, для которой будет производиться расчёт
* `T_base` - температура, для которой был получен рестарт-файл

Для запуска файла `in.npt` в рабочей директории должен быть файл с именем вида `${phase}.T${T_base}.restart` 
(например, `liq.T0.95.restart`), который получается из предыдущих расчётов.

## Задание
1. Запустить входной файл `in.nvt` для температуры 0.9 и начальных плотностей пара и жидкости.
2. Определить по результатам расчётов давление насыщенного пара при температуре 0.9.
3. Выбрать схему численного интегрирования и шаг численного интегрирования по температуре (рекомендуется ~0.1).
4. Запусками `in.npt` для газа и жидкости получить промежуточные значения $`\tilde{P}`$ и значения в конце шагов интегрирования.
5. Получить давление насыщенного пара при температуре 1.1 (интегрирование вперёд по температуре) или 0.7 (интегрирование назад по температуре)

2. Что такое порядок аппроксимации схемы численного интегрирования?
