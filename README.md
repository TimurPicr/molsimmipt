`commented_script_example.lammps` Базовое МД моделирование. Команды прокомментированы.

# Список директорий
* `1_compare_potentials` Сравнение уравнения состояния (холодной кривой), получаемой с парным потенциалом Морзе и потенциалом погруженного атома
* `2_reversibility` Исследование обратимости МД траектории при изменении шага по времени
* `3_energy_conservation` Исследование сохранения энергии в схемах Верле и rRESPA
* `4_NVT_MD` Сопоставление свойств в рамках NVT ансамбля в методе Монте-Карло и молекулярной динамики
* `5_GibbsDuhem` Расчет кривой испарения путем интегрирования уравнения Гиббса-Дюгема
* `6_ThermoInt` Расчет химического потенциала методом термодинамического интегрирования
* `7_transport` Оценка коэффициентов переноса
* `8_coulomb` Оценка точности различных приближений для вычисления кулоновских сил
* `9_twophase` Двухфазное моделирование
* `10_opt_saddle` Поиск минимума энергии и седловых точек в атомистической системе
* `surface_tension` Расчет поверхностного натяжения
